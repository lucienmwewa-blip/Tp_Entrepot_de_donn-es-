
# Processus ETL

Le processus ETL comprendra trois phases :

1. **Extraction** : lecture des données commerciales sources.
2. **Transformation** : nettoyage, contrôle des références, validation des dates, vérification des quantités et des prix, et gestion des doublons.
3. **Chargement** : insertion des données validées dans les dimensions et la table de faits de l'entrepôt.

Les lignes rejetées, les anomalies détectées et les volumes traités seront documentés afin d'assurer la traçabilité du traitement.
